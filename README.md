# Student Management System
A Python-based student management system that helps manage student records through a simple, menu-driven interface.
## Features
- Add and display students
- Search students by ID
- View fee and academic details
- Update student information
- Calculate grades and percentages
- Validate inputs and prevent duplicate IDs
## Technologies
- Python
- JSON
## How to Run
python project_student_management.py
## Data Storage
Student records are stored locally in `students.json`. This file is excluded from GitHub using `.gitignore` to protect student information.
